# Portfolio

Source for [aadhithyavijayakumar.com](https://www.aadhithyavijayakumar.com): a
static-first Next.js site for Aadhithya Vijayakumar, built for recruiters and
hiring managers who skim. It is live (v2.0, cut over 18 Nov 2026).

For the full record (stack rationale, what was built, verification results) see
[`docs/README.md`](docs/README.md). What comes next is in
[`docs/book-of-work.md`](docs/book-of-work.md) and the owner's own list is in
[`docs/owner-todo.md`](docs/owner-todo.md).

## Live setup

- **Hosting:** Vercel Hobby (free). Pushing `v2` redeploys automatically.
- **Domain:** the bare domain redirects to `www`, which is the canonical address
  (`lib/site.ts`). DNS is managed outside this repo.
- **Analytics:** Google Analytics 4, ID in `lib/analytics.ts`. It loads only on
  the real domain, never on localhost or preview URLs, and stays off for Do Not
  Track and Global Privacy Control. Besides page views it sends `email_click` and
  `resume_download`. The site does not mention analytics.
- **Search:** canonical tag, `robots.txt` and `sitemap.xml` are generated by
  Next.js (`app/robots.ts`, `app/sitemap.ts`).

## The page

Hero, selected impact, experience timeline, skills, projects, areas of interest,
credentials, contact. Light and dark themes. The only motion is a scroll reveal,
the experience timeline, the interest drawings and a mouse-following highlight
(mouse only; touch screens get pressed-state feedback instead).

Not on the page: the **Router Lab**, a cost-routed LLM demo with provider
failover and an eval harness. It is built and tested but its endpoint is offline
(`app/api/_router/`) until it has a rate limit and measured results. The earlier
car, road and intro animation are archived in
[`docs/archive/route-car/`](docs/archive/route-car/).

## Stack

Next.js 16 (App Router) · React 19 · TypeScript (strict) · Tailwind CSS 4 ·
shadcn/ui · Lucide · Vitest. No animation library and no analytics package.

## Commands

```bash
npm run dev        # local dev server (syncs content/assets first)
npm run build      # production build
npm start          # serve the production build
npm run lint       # ESLint
npm run typecheck  # next typegen + tsc --noEmit
npm test           # Vitest: content rules, analytics guards, Router Lab
```

## Content

All copy lives in `content/` as JSON, validated by `content/schema.ts`. Pages
never hardcode copy. Unknown facts are written `[[TODO: …]]`, never invented.

The union of the owner's résumé variants is the source of truth, and the tests
enforce it: every skill and bullet must be on a variant, the never-claim list
must not appear, and the owner's writing rules hold (no colons or dashes in
bullets, no Java and Python in one bullet). Changing content means keeping
`npm test` green.

Images are canonical in `content/assets`; `scripts/sync-assets.mjs` copies them
to the git-ignored `public/assets` before `dev` and `build`.

## Structure

```
app/          Routes, layout, global styles, share card, robots and sitemap
components/   Page sections, nav, and shadcn primitives
content/      Typed JSON, assets, schema and honesty tests
lib/          Content selectors, site URL, analytics, Router Lab internals
scripts/      Asset sync
docs/         Project record, book of work, owner to-do, archive
```

## Rules

Read `CLAUDE.md` before changing anything. Plan first for changes touching more
than three files. No secrets in the client bundle and no `.env*` in git. No new
dependency without a stated reason. Commit messages are one plain line saying what
changed, with no prefix.
